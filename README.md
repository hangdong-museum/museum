# 박물관 보물찾기 출석체크

국립중앙박물관 현장활동용 웹앱 (Google Apps Script + 구글 시트 + 구글 드라이브)

- 학생: 학번·이름·공용코드로 입장 → 보물(유물) 힌트를 보고 이름 맞히기 → 유물 앞에서 얼굴이 나오게 인증 사진 촬영
- 사진은 먼저 **휴대폰에 저장**되고, 와이파이에 연결한 뒤 한꺼번에 업로드
- 교사: 학생 명단 기준 현황표(썸네일 포함), 보물별 사진 모아보기

## 파일 구성

```
src/
├─ Code.gs          서버 (시트·드라이브 처리, 정답 확인, 업로드)
├─ Index.html       학생 화면
├─ Admin.html       교사 화면 (?page=admin)
├─ Images.html      보물 기본 이미지 (보물 탭 이미지 칸이 비어 있을 때 사용)
└─ appsscript.json  프로젝트 설정 (서울 시간대, 웹앱: 나로 실행 / 모든 사용자)
```

## 설치

1. 새 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 붙여넣기, HTML 파일 `Index`, `Admin`, `Images` 추가 (대문자로 시작, 확장자 제외)
3. `setup` 함수 1회 실행 → 권한 허용 (고급 → 이동 → 허용)
4. 시트 탭 채우기
   - **학생**: `학년 | 반 | 번호 | 이름` (학번은 학년+반2자리+번호2자리로 자동 생성, 예: 3학년 1반 5번 → 30105)
   - **설정**: `공용코드`, `관리자코드` 변경 (`사진폴더ID`는 자동)
   - **보물**: 위치·힌트·질문·정답(`|`로 여러 개)·이미지(드라이브 파일ID/URL, 비우면 기본 이미지)
5. **배포 → 새 배포 → 웹 앱** / 실행 사용자: **나** / 액세스: **모든 사용자**
   - 학생용: `.../exec`
   - 교사용: `.../exec?page=admin`
6. 코드 수정 후에는 **배포 관리 → 연필 → 새 버전 → 배포** (URL 유지)

## clasp로 올리기 (선택)

```bash
npm i -g @google/clasp
clasp login
cp .clasp.json.example .clasp.json   # scriptId 입력 (Apps Script → 프로젝트 설정 → 스크립트 ID)
clasp push
```

## 시트 구조

| 탭 | 내용 |
|---|---|
| 설정 | 공용코드, 관리자코드, 사진폴더ID |
| 학생 | 학년, 반, 번호, 이름 |
| 보물 | 번호, 위치, 힌트1~4, 질문, 정답, 이미지 |
| 기록 | 학번, 이름, 보물, 정답시각, 사진시각(휴대폰 저장 시각), 사진파일ID, 사진링크, 썸네일ID — 학생×보물당 1행 |

## 데이터 사용량 (대략)

- 학생: 현장 1~2MB (화면·글꼴), 업로드 사진 1장 약 0.4MB (휴대폰에서 1280px로 축소 후 전송)
- 교사: 썸네일 1장 약 30KB, 화면에 보이는 것만 불러옴

## 활동 종료 후

편집기에서 `deleteAllPhotos` 실행 → 사진 폴더 휴지통 이동 + 기록 탭 사진 정보 삭제
