# 박물관 보물찾기 출석체크

국립중앙박물관 현장활동용 웹앱

- **화면**: GitHub Pages (`docs/`)
- **데이터**: Google Apps Script(`gas/`) → 구글 시트(명단·기록) + 구글 드라이브(사진)

학생은 학번·이름·공용코드로 입장 → 힌트를 보고 유물 이름 맞히기 → 유물 앞에서 얼굴이 나오게 인증 사진 촬영.
사진은 먼저 **휴대폰에 저장**되고, 와이파이에 연결한 뒤 한꺼번에 업로드합니다.
교사는 명단 기준 현황표(썸네일 포함)와 보물별 사진 모아보기로 확인합니다.

## 파일 구성

```
docs/                 ← GitHub Pages
├─ index.html         학생 화면
├─ admin.html         교사 화면
├─ config.js          Apps Script API 주소 (배포 후 입력)
└─ images/1~6.jpg     보물 기본 이미지
gas/                  ← Apps Script (구글 시트에 붙여넣기)
├─ Code.gs            API 서버 (doPost)
└─ appsscript.json
```

## 설치

### 1. 구글 쪽 (데이터)
1. 새 구글 시트 → **확장 프로그램 → Apps Script** → `gas/Code.gs` 내용 붙여넣기
2. `setup` 함수 1회 실행 → 권한 허용 (고급 → 이동 → 허용)
3. 시트 탭 채우기
   - **학생**: `학년 | 반 | 번호 | 이름` (학번 = 학년+반2자리+번호2자리, 예: 3학년 1반 5번 → 30105)
   - **설정**: `공용코드`, `관리자코드` 변경 (`사진폴더ID`는 자동)
   - **보물**: 위치·힌트·질문·정답(`|`로 여러 개)·이미지(URL/드라이브 파일ID, 비우면 `docs/images/번호.jpg`)
4. **배포 → 새 배포 → 웹 앱** / 실행 사용자: **나** / 액세스: **모든 사용자**
5. 나온 `…/exec` 주소 복사

### 2. GitHub 쪽 (화면)
1. `docs/config.js`의 `API_URL`에 위 주소 붙여넣기
2. 저장소 **Settings → Pages → Branch: `main` / 폴더: `/docs` → Save**
3. 주소
   - 학생: `https://아이디.github.io/저장소이름/`
   - 교사: `https://아이디.github.io/저장소이름/admin.html`

### 수정할 때
- 화면(`docs/`) 수정 → GitHub에 올리면 1~2분 뒤 반영
- `Code.gs` 수정 → **배포 관리 → 연필 → 새 버전 → 배포** (주소 유지, config.js 그대로)
- 명단·코드·보물 정보 → 시트에서 바로 수정 (배포 불필요)

## 시트 구조

| 탭 | 내용 |
|---|---|
| 설정 | 공용코드, 관리자코드, 사진폴더ID |
| 학생 | 학년, 반, 번호, 이름 |
| 보물 | 번호, 위치, 힌트1~4, 질문, 정답, 이미지 |
| 기록 | 학번, 이름, 보물, 정답시각, 사진시각(휴대폰 저장 시각), 사진파일ID, 사진링크, 썸네일ID — 학생×보물당 1행 |

## 활동 종료 후

Apps Script 편집기에서 `deleteAllPhotos` 실행 → 사진 폴더 휴지통 이동 + 기록 탭 사진 정보 삭제
